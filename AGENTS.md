# Project communication and documentation

- Communicate with the repository owner in Spanish unless they request otherwise.
- Write repository documentation, project-authored comments, tooling messages,
  release notes and release documentation in English.
- Preserve upstream source comments, licenses, original commit messages and
  historical Git objects unless the user specifically requests changing them.
- Clearly distinguish current validation from historical build-only or temporary
  boot reports. Preserve exact hashes, source revisions and technical evidence.
- Documentation and translation tasks must not change kernel behavior,
  configuration or published boot-image bytes.
- These language preferences do not grant device access or execution permission;
  inherited workspace limits and explicit user authorizations still apply.
